Q-Learning

Off-Policy

Updates using the maximum estimated next-state action value, regardless of which action the agent actually takes. Learns the optimal policy while still exploring.

Q(s,a) = Q(s,a) + alpha * [r + gamma * max Q(s',a') - Q(s,a)]

SARSA

On-Policy

Updates using the actually selected next action's Q-value. The policy used for learning matches the policy used for action selection, making it more conservative.

Q(s,a) = Q(s,a) + alpha * [r + gamma * Q(s',a') - Q(s,a)]
Note: Results shown are from actual agent-environment interaction on your configured environment. Both algorithms use the same starting position for a fair comparison.
